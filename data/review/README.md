# Prompt review

[prompts_checked.json](prompts_checked.json) records the manual review of harmful and harmless labels.
It reviews the selected prompts in [../refusal/prompts.json](../refusal/prompts.json).
`Approved` confirms the assigned label.
`Needs check` marks an unresolved case and states the concern.
`Excluded` records a decision to omit a prompt from pilot runs.
